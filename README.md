# kliq (test version)

Swipe LEGO sets you like, then find what you can build from the pieces you own.

**Heads-up for testers:** there are no accounts. Everyone shares the same
ratings and pieces, and everything resets when the app restarts.

This repo is generated by `deploy/prepare_deploy.py` in the main project; edit
the code there, not here. Data: [Rebrickable](https://rebrickable.com/downloads/).
